# studio：宏设计器 + 审计页

```bash
uv run cyber-worker studio          # http://127.0.0.1:9999
```

纯 Web：FastAPI + 原生 HTML / JS / Canvas，不依赖任何前端框架或桌面 UI 框架。支持 macOS 和 Windows。

- **设置**：顶栏齿轮 ⚙ 打开设置窗口（见下面「设置」）；外观默认深色，可改浅色或跟随系统。
- **新手引导**：每个页面第一次打开会自动出现一步步的高亮说明，顶栏「?」随时重看。

## 宏设计（`/`）

布局参考雷云的宏设计器：

| 区域 | 内容 |
| :--- | :--- |
| 顶栏 | 宏设计 / 审计切换、状态（空闲 / 录制中 / 执行中）、设置 ⚙、新手引导、急停 |
| 宏信息栏 | **宏选择器**（可搜索、按平台分组、未保存的草稿置顶，`Ctrl/⌘ + K` 打开）+ **新建 · 保存 · 删除**（放在一起；删除点两次确认，草稿叫「丢弃」）；窗口尺寸、变量数、页面数 |
| 左：添加步骤 | 点击、输入文本、按键、滚动、拖动、延迟、等待页面；插在选中步骤之后 |
| 中：步骤列表 | 全选、预计耗时、录制（▾ 选项：是否录制延迟）、撤销 / 重做、删除；悬停显示勾选框和拖动手柄 |
| 右上：画面 | 参考图 / 最新截图 / 运行截图；点击与滚动的编号标记和路径连线、页面锚点框、选中点击步骤的目标框（橙色）；截取当前窗口、框选锚点 |
| 右下：标签页 | **步骤参数**（选中步骤时自动切过来）· **宏设置**（名称、程序、变量、锚点）· **运行**（变量输入、空跑、执行、实时日志） |

**草稿**：新建的宏先是草稿（选择器里标「未保存」），录制、截图、框锚点、空跑都可以在草稿上做；点「保存」才存进宏库（`user_data/platforms/`）。草稿放在 `user_data/drafts/`，切换到别的宏不会丢。

**支持的操作**（录制和执行都支持）：

| 操作 | 录制时怎么判定 | 编辑 |
| :--- | :--- | :--- |
| 单击 / 双击 | 0.5 秒内原地点两下 = 双击 | 「方式」单击 / 双击 / 长按 |
| 长按 | 按住 ≥ 0.5 秒 | 长按秒数 |
| 拖动 | 按住移动 > 6 点 | 起点 / 终点（画面上圆点和方块都能拖）、用时 |
| 左键 / 右键 / 中键 | 按的哪个键 | 「按键」 |
| Ctrl / Shift / Alt / ⌘ + 点击或拖动 | 按下鼠标时按住的修饰键 | 「同时按住」 |
| 滚轮（纵向 / 横向） | 1 秒内、附近、同方向的滚动合并；触控板的小数格累计 | 纵向、横向格数 |
| 按键、按住不放的连按 | 0.6 秒内同一个键连按合并成次数 | 组合键、次数 |

执行时凡是「按下不放」的（长按、拖动、修饰键），任何中断（急停、你动了鼠标、出错）都会先松开。

**按图找**：录制时每次按下鼠标，都会截下点击处周围的一小块。这块有纹理、在窗口里独一无二（头像、按钮），这一步就自动设成「按图找」，列表里标着橙色的「按图」；点在空白处、纯色输入框就保持固定坐标。执行时先在窗口里找这块图，找到了点在它上面，界面变了（来了新消息，群在列表里换了位置）也能点中；找不到就等（默认最多 5 秒），超时中止，**不会退回去点旧坐标**。运行日志里会写「按图找到目标，位置偏了 +0, −100」。步骤参数里可以：
- 切换定位方式：「按图找 / 固定坐标」；
- 看目标图缩略图，改「最多等几秒」；
- 点「重新框选」在画面上框一块新的目标（固定坐标的点击也能补一块）。

**等页面**：输入、发送这类要核对页面的步骤，页面还没出现会等（最多 5 秒），不是核对一次对不上就中止。需要在别处等的，用「等待页面」步骤：选一个页面、设最多等几秒，等到锚点对上了才往下走，比固定延迟靠谱。

**跨窗口**：一个宏可以跨多个窗口，比如在 QQ 主窗口双击会话，再到弹出的聊天窗口里打字。录制时每次点击看鼠标下面实际是哪个窗口、每次打字看前台是哪个窗口，新出现的窗口登记成「窗口 2、3…」（按标题认，标题里会变的「等N个会话」自动去掉），步骤上会标出窗口名。执行时每一步先切到它的窗口；上一步才打开的窗口最多等 6 秒。页面锚点也按窗口分别自动生成。

**中文输入法**：键盘监听只看得到按键（比如 `nihao`），看不到你最后选的字。录制时如果开着中文输入法，这一步会被标出来并自动选中，请在右边填上实际要输入的文字；没改之前执行到这一步会停下，不会把拼音打出去。

**输入框里原有的内容**：输入步骤默认「输入前先清空输入框」，会清掉输入框里原来的内容（包括你没发出去的草稿）。不想清就在步骤参数里关掉。

没有宏、宏里没有步骤时，列表区域会给出下一步该做什么的提示和按钮。

### 典型流程

第一次用：点「点一下目标窗口，开始录制」→ 切过去点一下那个窗口（比如聊天窗口）→ 已经在录了，像平时一样操作 → 回来点「停止」→ 去「运行」空跑。**全程不用填任何东西。**

1. **新建宏**：「新建宏」→「点一下目标窗口」，然后去点那个窗口，**直接创建**：程序、标题、尺寸自动识别，宏名用窗口标题（QQ「…等2个会话」这种会变的部分自动去掉）。也可以从列表里点一个（最小化的窗口也在列表里）。想自己改名或尺寸，展开「自定义名称、尺寸…」。
2. **录制**：点「录制」或**在任何窗口里按 `Alt+R`**（macOS `⌥R`），到目标窗口里操作，做完**再按一下 `Alt+R`** 就停止，不用切回 studio（也可以回来点「停止」）。按快捷键开始时，录的是 studio 里当前打开的宏；快捷键本身不会被录进宏。操作间隔录成单独的延迟行（可在 ▾ 里关掉）；在同一位置快速点两下会录成一个「双击」步骤（打开聊天、打开文件都需要双击）。录完自动：
   - 最后一次输入之后紧跟的那次点击或回车，**标成「发送」**；
   - 从录制期间的截图里**自动选一块页面锚点**（整个录制过程中没变过、有辨识度、画面里独一无二的区域，比如聊天对象名字），命名「页面1」，**自动填给**输入和发送步骤；
   - 画面切到录制的最后一帧，蓝色虚线框就是自动选的锚点。
3. **整理**（可选）：删掉多余的步骤、改延迟、在画面上拖动标记修正坐标。
4. **自己框锚点**（可选，自动选的不合适时）：「截取当前窗口」→「框选锚点」→ 拖出区域 → 直接回车（名字自动是「页面N」）。还没指定页面的输入 / 发送步骤会自动填上。
5. **变量**：在输入步骤里点「+ {评论内容}」插入变量，或者直接写 `{任意名字}`，会自动声明。
6. **运行**标签：填变量 → **空跑** → 点日志看每一步截图 → **执行**（点两次确认）。

列表里的黄色 ⚠ 会提示还缺什么。输入步骤默认「输入前先清空输入框」，空跑或被打断后留下的文字不会跟着下一次一起发出去。

### 快捷键

| 键 | 作用 |
| :--- | :--- |
| `Alt + R`（任何窗口；macOS `⌥R`） | 开始 / 停止录制 |
| `Ctrl + Alt + Shift + .`（任何窗口；macOS `⌃⌥⌘.`） | 急停 |
| `Ctrl/⌘ + K` | 打开宏选择器 |
| `Ctrl/⌘ + S` | 保存 |
| `Ctrl/⌘ + Z` / `Ctrl/⌘ + Shift + Z` | 撤销 / 重做 |
| `Delete` | 删除勾选（或选中）的步骤 |
| `↑` / `↓` | 上下切换步骤 |
| `Esc` | 退出框选 / 取消选中 |
| 引导中 `←` `→` / `Esc` | 上一步、下一步 / 跳过 |

前两个是**全局快捷键**，可以自己改：顶栏 ⚙ →「快捷键」，点一下输入框、直接按下想要的组合键，当场显示能不能用（能用就立即生效，有冲突就不改）：

| 提示 | 意思 | 会生效吗 |
| :--- | :--- | :--- |
| 可以用 | 没有冲突 | ✓ |
| 已被其他程序占用 | 别的软件（截图、录屏、输入法……）已经注册了这个键（Windows 上向系统试注册查出来的） | ✗ |
| 系统保留 | 复制粘贴、切换窗口、Win 键组合这类系统或日常常用键 | ✗ |
| 和另一个快捷键重复 | 录制开关和急停不能是同一个键 | ✗ |
| 单独一个键会影响打字 | 要加 Ctrl / Alt / Shift（F1–F24 可以单独用） | ✗ |
| 查不到其他软件的占用 | macOS 上没法查别的软件占没占，按了没反应就换一个 | ✓ |

生效的同时写进 `config.toml`（`[studio] record_hotkey`、`[executor] panic_hotkey`），不用重启；「恢复默认」一键改回。录新键时会先临时放开全局快捷键（不然按下去会被系统拦走），录完自动恢复。

**启动时自动避让**：Windows 上快捷键向系统独占注册。配置的键如果已经被别的软件占了，会自动换成第一个空闲的备选（录制：`Alt+Shift+R` → `Ctrl+Alt+F9` → `Ctrl+Alt+F10` → `Ctrl+Shift+F9`；急停：`Ctrl+Alt+F12` → `Ctrl+Shift+F12`），终端和页面上都会提示换成了哪个。按钮、状态栏、新手引导里显示的永远是实际生效的键。

### 设置

顶栏齿轮 ⚙ 打开（宏设计页和审计页都有）。左边分类、右边设置项，**改了立即生效**，同时写进 `config.toml`，不用点保存、不用重启；窗口标题旁会闪一下「已保存」。

| 分类 | 设置项 | 写在 config.toml |
| :--- | :--- | :--- |
| 通用 | 外观：深色（默认）/ 浅色 / 跟随系统 | `[studio] theme` |
| 快捷键 | 开始 / 停止录制、急停（见上面「快捷键」）；下面列出页面内快捷键 | `[studio] record_hotkey`、`[executor] panic_hotkey` |
| 录制与执行 | 录制延迟（和录制按钮旁 ▾ 里是同一个开关） | `[studio] record_delays` |
| | 开始前等你停手：点空跑 / 执行后等键鼠停几秒才开始（默认 2 秒） | `[studio] run_idle_sec` |
| | 你在用电脑时暂停、空闲多久后继续（无人值守执行用） | `[executor] pause_on_user_input`、`resume_after_idle_sec` |
| 关于 | 版本、配置文件位置、数据目录、重新看新手引导 | — |

以 `config.toml` 为准：在别的浏览器里打开也是同样的设置；开着两个页面时，一边改了另一边跟着变。

### 执行与安全

- studio 里点「空跑」或「执行」后，要等你的键鼠**停下 2 秒**才开始（无人值守运行时是 `config.toml` 的 `resume_after_idle_sec`）。等待期间按钮区显示「鼠标别动，2 秒后自动开始」，旁边有「取消」；开始后显示「正在执行…」
- 执行中你一动键鼠，当前步骤立即中止
- 录制和执行互斥；任何时候可以点「急停」或按急停热键（默认 macOS `⌃⌥⌘.`，Windows `Ctrl+Alt+Shift+.`；可在设置里改）

## 审计（`/audit`）

- 顶部：当天运行次数、步骤数、成功率（空跑正常停在发送前算成功，急停不计入）、可疑待审数
- 列表按**可疑度**排序（左侧色条越红越可疑）：执行出错 > 页面不符中止 > 页面得分偏低 > 没做页面校验的步骤 > 正常
- 每天随机抽几条「看起来成功」的记录标为「抽查」
- 右侧显示操作后截图、预期页面、页面得分、说明
- `1` 没问题 · `2` 有问题 · `0` 重置；标完自动跳到下一条；`J` / `K` 上下

## 接口

| 方法 | 路径 | 说明 |
| :--- | :--- | :--- |
| GET | `/api/windows` | 当前打开的窗口（含最小化的，不含 studio 自己），附带建议的宏名 `suggested_name` 和认窗口用的标题 `match_title` |
| POST | `/api/windows/pick` | 等用户下一次真实点击（20 秒），返回点到的窗口；点到 studio 自己不算 |
| GET | `/api/scripts` | 宏列表（`user_data/platforms/*/templates/*.yaml`） |
| POST | `/api/scripts` | 新建空白宏**草稿**（校准窗口 + 参考图）；只需 `name`、`app`、`width`、`height`，平台按程序名生成，重名自动加序号 |
| POST | `/api/scripts/{id}/commit` | 把草稿保存进宏库（连同参考图、页面锚点一起搬） |
| GET / PUT / DELETE | `/api/scripts/{id}/detail` | 读取 / 保存 / 删除 |
| POST | `/api/scripts/{id}/capture` | 截取当前窗口 |
| POST / DELETE | `/api/scripts/{id}/anchors[/{page}/{index}]` | 添加 / 删除页面锚点 |
| POST | `/api/scripts/{id}/targets` | 在画面上框一块，作为某个点击步骤「按图找」的目标图 |
| POST | `/api/record/start`、`/api/record/stop` | 录制（追加到宏末尾） |
| POST | `/api/scripts/{id}/run` | 空跑 / 执行（进全局执行器排队） |
| POST | `/api/panic` | 急停 |
| GET / PUT | `/api/hotkeys` | 全局快捷键：实际生效的键、配置的键、默认键、自动避让说明 / 改键（有冲突返回 400；通过就写回 `config.toml` 并立即重新注册） |
| POST | `/api/hotkeys/check` | 检查一个组合键：`ok` / `unknown` / `taken` / `reserved` / `duplicate` / `invalid` |
| POST | `/api/hotkeys/suspend`、`/api/hotkeys/resume` | 录新键时临时放开全局快捷键（30 秒后自动恢复） |
| GET / PATCH | `/api/settings` | 外观、录制与执行的设置，以及版本、配置文件和数据目录位置；PATCH 立即生效并写回 `config.toml` |
| GET / POST | `/api/audit`、`/api/audit/{entry_id}` | 审计列表 + 日报 / 标记 |
| WS | `/ws` | `record`、`record_state`、`record_done`、`run_entry`、`run_state`、`hotkeys`、`settings`、`toast` 事件 |
