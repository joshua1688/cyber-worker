# studio：流程设计器 + 审计页

> 界面上按「应用 › 流程 › 步骤」组织：一个应用就是一个平台包（`user_data/platforms/<平台>/`），一个流程就是录下来的一串操作（`flows/*.yaml`），流程里是一步步的步骤。代码、文件夹和 [flow.md](flow.md) 里应用仍叫平台。

```bash
uv run cyber-worker studio          # http://127.0.0.1:9999
```

纯 Web：FastAPI + 原生 HTML / JS / Canvas，不依赖任何前端框架或桌面 UI 框架。支持 macOS 和 Windows。

只接受本机 studio 页面发来的请求：地址必须是 `127.0.0.1` / `localhost`，别的网页发来的请求（带了别的 Origin）和 WebSocket 连接一律拒绝（403）。浏览器里开着的其他网站不能借 studio 执行流程、读截图或收实时推送（包括「DNS 重绑定」这种把别的域名临时指向本机的做法）。

**旧图自动清理**：重新录制、替换录制画面时，旧的步骤画面、目标图、参考图会留着给 Ctrl+Z 用（`s01-2.png` 这类）。studio 启动时把没有任何步骤或页面再引用、而且放了 3 天以上的这些图删掉。

- **设置**：顶栏齿轮 ⚙ 打开设置窗口（见下面「设置」）；外观默认深色，可改浅色或跟随系统。
- **新手引导**：每个页面第一次打开会自动出现一步步的高亮说明，顶栏「?」随时重看。

## 应用（`/apps`）

打开 studio 先到这里（`/` 没指定流程时也跳到这里）。一个**应用**就是一个软件或网站（QQ、微信、B站…），里面放它的各种流程；文件上就是流程库里的一个平台目录 `user_data/platforms/<平台>/`，界面上统一叫「应用」。

- **应用总览**：内容居中、最宽 1040px，每行 3 张卡片（几个流程、流程名、今天运行几次 / 几次失败）；应用名用主窗口标题（同一个应用里最常见的那个，没有标题才用程序名）。最后一张虚线卡片是「新建应用」（只有 ＋ 和四个字）= 去点一下要自动化的程序窗口，建好就开始录第一个流程；「导入应用包」或把 `.cwpack` 拖进页面。标题下是「N 个应用 · N 个流程」，下面一直有搜索（按应用名或流程名）和排序（最近用过 / 名字，记在本机）；一个应用都没有时标题下是一句介绍。
- **应用首页**（`/apps?app=qq`）：「应用 › QQ」，它的流程一张张卡片，只放要紧的：名字、一句话说明（没有就不显示，鼠标移上去才出现「＋ 加一句说明」）、几步、大概多久、最近一次运行（成功 / 空跑通过 / 失败；失败的写出是第几步、为什么，点一下直接打开那一步）。鼠标移到卡片上，名字和说明旁边出现 ✎：点一下原地改名 / 写说明（Enter 或点别处保存，Esc 取消；同一个应用里重名自动加 -2；改名后以前的运行记录跟着改名，「最近一次」不会丢），点卡片别的地方进流程设计。按「全部 / 失败 / 没跑过」筛选、搜索；「编辑」「空跑」进流程设计；「录一个新流程」= 点一下窗口、建在这个应用下、开始录制；它右边的 ⋯ 里是「导出应用包」（打包这个应用）和「删除这个应用」，点两次才删（第一次写明「确认删除 QQ 和它的 N 个流程」），整个应用挪进 `user_data/.trash/`，回到总览时提示「已删除 · 撤销」，7 天内没撤销的在 studio 启动时清掉；审计记录不删。
- 流程设计页左上角是「‹ QQ › 群聊天」：‹ 回到这个应用的首页，点名字切到别的流程。

## 流程设计（`/?flow=…`）

布局：

| 区域 | 内容 |
| :--- | :--- |
| 顶栏 | 流程设计 / 审计切换、状态（空闲 / 录制中 / 执行中）、设置 ⚙、新手引导、急停 |
| 流程信息栏 | 左边 **流程选择器**（可搜索、按应用分组，`Ctrl/⌘ + K` 打开；下拉底部「新建流程」「导入应用包」；副标题显示「已自动保存 / 正在保存…」）；右边三个主操作 **录制（▾ 录制选项）· 空跑 · 执行**，任何时候都看得到 |
| 左：步骤列表 | 全选、「4 步 · 6.3 秒」（延迟不算步，时长照算）、顶部的 **「＋」**（加在最后）；**右键一步**（或点它右边的 ⋯）：在后面添加 ›、在前面添加 ›、换成 ›、复制一份（Ctrl+D）、删除（Del），「添加」「换成」往右弹出 8 种类型（点击、输入文本、按键、滚动、悬停、拖动、延迟、等待页面）；在列表空白处右键、或空流程里点「手动添加一步」，直接选类型加在最后。新步骤放在画布上正显示的那个窗口、那张画面上，默认位置是这个窗口的中心，前后挨着的不是延迟就各垫一个 1 秒延迟（加的本身是延迟时不垫），在前面、后面添加都一样。「换成」就地换类型：编号、窗口、那张画面、备注不变，位置、所在页面、「发送」标记新类型用得上就沿用，可撤销。复制出来的那一步不带「发送」标记。按键步骤：点一下「按键」框再按键盘（Enter、Esc、方向键、F1–F12、Ctrl+V 这类组合都行），框里显示成「Ctrl + V」；下面一排常用键点一下就填；Ctrl+W、Ctrl+T、Win 这类会被浏览器或系统先抢走，录不到时用常用键或「手动输入」、撤销 / 重做、删除；每行下面一行是窗口、按图、发送、页面这些标签；悬停显示勾选框和拖动手柄 |
| 中：画面 | 录制画面 / 当前画面 / 运行截图，每个窗口各一套（跟着选中的步骤切换，也可手动切）；点击与滚动的编号标记和路径连线、输入 / 按键的方块标记（标在它打进去的地方，也就是前面那次点击旁边；选中时圈出「输入到这里」，只显示、不能拖）、页面锚点框、选中点击步骤的目标框（橙色）；右上角「截图」截一张窗口现在的样子（并切到「当前画面」），「框锚点」在画面上框一块锚点；窗口切换按钮显示窗口的真实名字（如「QQ」「My Sky」） |
| 右：面板 | **步骤**（选中步骤时自动切过来；说明收在 ⓘ 里，不常用的选项在「更多」里）· **流程设置**（名称、程序、变量、锚点；最下面「删除这个流程」，点两次确认）· **运行**（变量输入、空跑 / 执行的进度和取消、实时日志） |

**应用包（导出 / 导入）**：应用页的「⋯ › 导出应用包」或选择器里每个应用分组旁的「导出」，一键下载 `<应用目录名>.cwpack`，里面是这个应用的全部流程连同页面锚点、按图找的目标图，以及录制时的窗口截图（每个窗口的参考图、每一步的画面），导入的人打开流程就能看到每一步在哪操作。截图里可能有聊天内容：导出后会提示一句；不想带就在设置 › 录制与执行 › 「导出时带上截图」关掉（执行只看锚点和目标图，不受影响）。草稿、运行截图不打进去。别人点应用总览的「导入应用包」或下拉底部的「导入应用包」选文件，或者直接把 `.cwpack` 拖进页面就导入完成，不弹任何确认。包会先整体校验（只收 yaml / json / png、不能跳出目录、流程和锚点文件必须有效），有一处不对整包拒绝；同名的流程自动加 `-2`，显示名也跟着加。

**自动保存**：没有「保存」按钮。新建的流程直接进流程库（`user_data/platforms/`），之后的每次修改停一下就自动写回（选择器副标题会闪一下「正在保存…」），`Ctrl/⌘ + Z` 撤销。录制、截图、框锚点、空跑之前也会先把没写回的修改写回。

**支持的操作**（录制和执行都支持）：

| 操作 | 录制时怎么判定 | 编辑 |
| :--- | :--- | :--- |
| 单击 / 双击 | 0.5 秒内原地点两下 = 双击 | 「方式」单击 / 双击 / 长按 |
| 长按 | 按住 ≥ 0.5 秒 | 长按秒数 |
| 拖动 | 按住移动 > 6 点 | 起点 / 终点（画面上圆点和方块都能拖）、用时 |
| 悬停 | 鼠标在目标程序里停住，停之后**画面真的变了**才记：弹出了新窗口（资料卡）、或停的那个窗口内容明显变了（悬停菜单）。随手停一下、停着时又点了 / 打字了都不记 | 位置（画面上是虚线圈）、停多久、按图找（比如头像）。停不到半秒就移开的（移动途中顿一下）不算；手抖几个点不算移开；资料卡晚一点弹出（最多等 3 秒）也认得出 |
| 左键 / 右键 / 中键 | 按的哪个键 | 「按键」 |
| Ctrl / Shift / Alt / ⌘ + 点击或拖动 | 按下鼠标时按住的修饰键 | 「同时按住」 |
| 滚轮（纵向 / 横向） | 1 秒内、附近、同方向的滚动合并；触控板的小数格累计 | 纵向、横向格数 |
| 按键、按住不放的连按 | 0.6 秒内同一个键连按合并成次数 | 组合键、次数 |

执行时凡是「按下不放」的（长按、拖动、修饰键），任何中断（急停、你动了鼠标、出错）都会先松开。

**悬停弹出的窗口**（资料卡这种）：录制时自动标成「弹出窗口」（`Window.popup`）。执行时对它只找位置，不切前台、不改尺寸——一抢焦点卡片就没了。

**按图找**：录制时每次按下鼠标，都会截下点击处周围的一小块。这块有纹理、在窗口里独一无二（头像、按钮），这一步就自动设成「按图找」，列表里标着橙色的「按图」；点在空白处、纯色输入框就保持固定坐标。执行时先在窗口里找这块图，找到了点在它上面，界面变了（来了新消息，群在列表里换了位置）也能点中；找不到就等（默认最多 5 秒），超时中止，**不会退回去点旧坐标**。目标图常常是鼠标悬停时的样子（按钮带灰底）：执行时如果只找到一处「挺像但不够像」的，会先把鼠标移过去让它亮起来，再接着找。运行日志里会写「按图找到目标，位置偏了 +0, −100」。步骤参数里可以：
- 切换定位方式：「按图找 / 固定坐标」；
- 看目标图缩略图，改「最多等几秒」；
- 点「重新框选」在画面上框一块新的目标（固定坐标的点击也能补一块）。
- 按钮样子变了一点（换了颜色、多了个角标）不用管：执行时找到了但得分偏低（0.80–0.90）、窗口里又只有一处像它，程序会自动记住它现在的样子，下次两种都认，运行记录里写「按钮样子变了，已自动记住新样子」。录制时的目标图一直保留。录制时也会自动多存一张按钮「平时没碰到时」的样子（目标图截在按下那一刻，按钮常带着按下的颜色）。真找不到了（执行中止）才需要「重新框选」。

**等页面**：输入、发送这类要核对页面的步骤，页面还没出现会等（最多 5 秒），不是核对一次对不上就中止。需要在别处等的，用「等待页面」步骤：选一个页面、设最多等几秒，等到锚点对上了才往下走，比固定延迟靠谱。

**跨窗口**：一个流程可以跨多个窗口，比如在 QQ 主窗口双击会话，再到弹出的聊天窗口里打字。录制时每次点击看鼠标下面实际是哪个窗口、每次打字看前台是哪个窗口，新出现的窗口登记成「窗口 2、3…」（按标题认，标题里会变的「等N个会话」自动去掉），步骤上会标出窗口名。执行时每一步先切到它的窗口；上一步才打开的窗口最多等 6 秒。重新录到以前录过的窗口时，尺寸按这次的实际尺寸记；没有步骤、也没有锚点再用到的旧窗口，录完自动去掉。页面锚点也按窗口分别自动生成。每个窗口各有一张参考图（录制时它出现的第一帧，存在 `<流程名>.refs/` 里）和一张最新截图：在步骤列表里选中哪一步，右上画面就切到它所在的窗口，能直接在上面看标记、框锚点和目标；画面上方的窗口切换也可以手动选（只列步骤用到的窗口）。

**每一步的画面**：录制时每一步在动作之前截一张它所在的窗口（点击在按下那一刻，输入 / 按键 / 滚动在开始时），存在 `<流程名>.shots/`。和同一个窗口上一张存下的图比，真的变了（点开会话、弹出菜单、新消息）才另存，没变或只是多了几个字就共用上一张。选中一步，「参考图」显示的就是这一步录制时的画面（画面上方写着「第 N 步录制时的画面」），标记画在上面；在这张画面上也能直接框锚点、重框目标图。没有步骤画面的（以前录的、手动添加的）显示窗口参考图。选中「延迟」不显示画面（它不操作任何窗口，参数里也没有「窗口」）；选中「等待页面」显示那个页面锚点所在窗口的参考图，它等的锚点高亮；它的窗口自动取锚点所在的窗口，换页面时跟着换。以前录的流程没有聊天窗口的参考图，打开那个窗口后点一次「截图」就会补上。选中步骤时画面类型保持你选的：停在「当前画面」就把每一步都标在最新截图上，方便对照现在的窗口。

**录制画面录错了**：先把窗口摆成这一步操作之前该有的样子，选中这一步、停在「录制画面」，点「截图」旁边的 ▾ →「替换录制画面」，就用现在的窗口换掉这张录制画面（和它共用同一张图的几步一起换）；没选步骤就换这个窗口的录制画面。只换图，坐标、目标图、页面锚点都不动；新图另存、旧图留着，Ctrl+Z 换回原来的。「截图」按钮只截一张当前画面，不会换掉录制画面。

**中文输入法**：键盘监听只看得到按键（比如 `nihao`），看不到你最后选的字。录制时如果开着中文输入法，这一步会被标出来并自动选中，请在右边填上实际要输入的文字；没改之前执行到这一步会停下，不会把拼音打出去。

**输入框里原有的内容**：输入步骤默认「输入前先清空输入框」，会清掉输入框里原来的内容（包括你没发出去的草稿）。不想清就在步骤参数里关掉。

没有流程、流程里没有步骤时，列表区域会给出下一步该做什么的提示和按钮。

### 典型流程

第一次用：点「点一下目标窗口，开始录制」→ 切过去点一下那个窗口（比如聊天窗口）→ 已经在录了，像平时一样操作 → 回来点「停止」→ 点上面的「空跑」。**全程不用填任何东西，也不用点保存。**

1. **新建流程**：「新建流程」→「点一下目标窗口」，然后去点那个窗口，**直接创建**：程序、标题、尺寸自动识别，流程名用窗口标题（QQ「…等2个会话」这种会变的部分自动去掉）。也可以从列表里点一个（最小化的窗口也在列表里）。想自己改名或尺寸，展开「自定义名称、尺寸…」。
2. **录制**：点「录制」或**在任何窗口里按 `Alt+R`**（macOS `⌥R`），到目标窗口里操作，做完**再按一下 `Alt+R`** 就停止，不用切回 studio（也可以回来点「停止」）。按快捷键开始时，录的是 studio 里当前打开的流程；快捷键本身不会被录进流程。操作间隔录成单独的延迟行（可在 ▾ 里关掉）；在同一位置快速点两下会录成一个「双击」步骤（打开聊天、打开文件都需要双击）。录完自动：
   - 最后一次输入之后紧跟的那次点击或回车，**标成「发送」**；
   - 从录制期间的截图里**自动选一块页面锚点**（整个录制过程中没变过、有辨识度、画面里独一无二的区域，比如聊天对象名字），命名「页面1」，**自动填给**输入和发送步骤。重新录制时，如果这个窗口已有的页面对得上最后的画面，就**沿用**它，不会再多出一个「页面2」；覆盖录制结束后，没有任何步骤再用的页面会收起来（画面上不再显示）。锚点图先留着：按 Ctrl+Z 撤销这次录制，旧步骤用到的页面会自动回来；收起超过 3 天的才真正删掉；
   - 画面切到录制的最后一帧，蓝色虚线框就是自动选的锚点。
3. **整理**（可选）：删掉多余的步骤、改延迟、在画面上拖动标记修正坐标。
4. **自己框锚点**（可选，自动选的不合适时）：画面右上角的「截图」→ 旁边的「框锚点」→ 拖出区域 → 直接回车（名字自动是「页面N」）。还没指定页面的输入 / 发送步骤会自动填上。
5. **变量**：在输入步骤里点「+ {评论内容}」插入变量，或者直接写 `{任意名字}`，会自动声明。
6. **空跑、执行**：顶部右边的「空跑」（或在任何窗口里按 `Alt+T`，录完不用切回来就能验证）→ 右边「运行」里点日志看每一步截图 → 「执行」（点两次确认，或在 studio 里按两次 `Ctrl/⌘ + Enter`）。有变量的流程先在「运行」里填变量。执行会真的发送，所以**没有**全局快捷键。空跑和执行开始时都会响一声（按钮和快捷键一样），人在目标窗口里也知道它开始了。

列表里的黄色 ⚠ 会提示还缺什么。输入步骤默认「输入前先清空输入框」，空跑或被打断后留下的文字不会跟着下一次一起发出去。

### 快捷键

| 键 | 作用 |
| :--- | :--- |
| `Alt + R`（任何窗口；macOS `⌥R`） | 开始 / 停止录制 |
| `Alt + T`（任何窗口；macOS `⌥T`） | 空跑 studio 里当前打开的流程（用「运行」标签里填的变量；页面上有没保存的修改时，会先保存再跑，和点「空跑」一样） |
| `Ctrl + Alt + Shift + .`（任何窗口；macOS `⌃⌥⌘.`） | 急停 |
| `Ctrl/⌘ + Enter` 按两次 | 执行（第一下只是准备，4 秒内再按一下才执行） |
| `Ctrl/⌘ + K` | 打开流程选择器 |
| `Ctrl/⌘ + S` | 立刻保存（平时是自动保存的） |
| `Ctrl/⌘ + Z` / `Ctrl/⌘ + Shift + Z` | 撤销 / 重做 |
| `Delete` | 删除勾选（或选中）的步骤 |
| `↑` / `↓` | 流程设计页：上下切换步骤；审计页：上下切换运行 |
| `←` / `→` | 审计页：切换这次运行的上一步 / 下一步 |
| `Esc` | 退出框选 / 取消选中 |
| `1` / `2` | 审计页：看过了 / 有问题，要修（再按一次撤销） |
| 引导中 `←` `→` / `Esc` | 上一步、下一步 / 跳过 |

前两个是**全局快捷键**，可以自己改：顶栏 ⚙ →「快捷键」，点一下输入框、直接按下想要的组合键，当场显示能不能用（能用就立即生效，有冲突就不改）：

| 提示 | 意思 | 会生效吗 |
| :--- | :--- | :--- |
| 可以用 | 没有冲突 | ✓ |
| 已被其他程序占用 | 别的软件（截图、录屏、输入法……）已经注册了这个键（Windows 上向系统试注册查出来的） | ✗ |
| 系统保留 | 复制粘贴、切换窗口、Win 键组合这类系统或日常常用键 | ✗ |
| 和另一个快捷键重复 | 录制开关和急停不能是同一个键 | ✗ |
| 单独一个键会影响打字 | 要加 Ctrl / Alt / Shift（F1–F24 可以单独用） | ✗ |
| 查不到其他软件的占用 | macOS 上没法查别的软件占没占，按了没反应就换一个 | ✓ |

生效的同时写进 `config.toml`（`[studio] record_hotkey`、`[studio] dry_run_hotkey`、`[executor] panic_hotkey`），不用重启；「恢复默认」一键改回。录新键时会先临时放开全局快捷键（不然按下去会被系统拦走），录完自动恢复。

**启动时自动避让**：Windows 上快捷键向系统独占注册。配置的键如果已经被别的软件占了，会自动换成第一个空闲的备选（录制：`Alt+Shift+R` → `Ctrl+Alt+F9` → `Ctrl+Alt+F10` → `Ctrl+Shift+F9`；急停：`Ctrl+Alt+F12` → `Ctrl+Shift+F12`），终端和页面上都会提示换成了哪个。按钮、状态栏、新手引导里显示的永远是实际生效的键。

### 执行与安全

- studio 里点「空跑」或「执行」后，要等你的键鼠**停下 2 秒**才开始（无人值守运行时是 `config.toml` 的 `resume_after_idle_sec`）。等待期间按钮区显示「鼠标别动，2 秒后自动开始」，旁边有「取消」；开始后显示「正在执行…」
- 执行中你一动键鼠，当前步骤立即中止
- 录制和执行互斥；任何时候可以点「急停」或按急停热键（默认 macOS `⌃⌥⌘.`，Windows `Ctrl+Alt+Shift+.`；可在设置里改）

## 审计（`/audit`）

- 顶部：当天运行次数、成功率（空跑正常停在发送前算成功，急停不计入）、失败次数、待审步数
- 筛选：日期（今天排第一）、流程（下拉按应用分组：「全部 QQ 的流程」、QQ 里的一个个流程；不同应用里同名的流程也分得清）、**全部 / 待审 / 失败 / 要修**
- 列表**一次运行一行，两行字**：第一行是应用头像 +「QQ › 群聊天 空跑」和时间，第二行一句人话原因（「窗口尺寸不对（要 320×740，实际 580×740）」「第 4 步：找不到「直播源」窗口」「你在用电脑，已停下」）。左边小圆点：红 = 失败 / 中止，黄 = 还有可疑的步骤没看，绿 = 正常；只有圆点是彩色的。按运行里最该看的那一步排序（执行出错 > 页面不符中止 > 页面得分偏低 > 没做页面校验的步骤 > 正常）
- **连着几次同一个流程、同样的失败合成一行**，标着「×N」；右上角「同样的还有 18:02」可以切过去看；标记时这几次一起标
- 右侧标题同样写「QQ › 群聊天 · 执行」，点「QQ」回到这个应用的页面。每条审计记录都记着它属于哪个应用；加这一项以前的旧记录按流程名认应用，流程名在好几个应用里都有的就只写流程名，不乱猜
- 右侧：这次运行的**步骤时间线**（每步一个圆点，点哪步看哪步）→ 原因卡片（人话原因；核对页面和得分、程序原文放在下面一行小字）→ 操作后截图（没有截图就一行字说明，不留大块空白）
- **复核按一次运行来标**，两个按钮，再点一次就是撤销：
  - **看过了**（`1`）：这次运行看过、没问题，自动跳到下一次；列表里标「✓ 看过」、字变灰
  - **有问题，要修**（`2`）：程序以为做对了、其实做错了（最危险的情况）。列表里标红色「要修」，留在「要修」筛选里；旁边「去修改」直接打开那个流程、选中出问题的那一步（流程已经删了就是灰掉的「流程已删除」；流程设计页支持 `/?flow=<id>&step=<步骤编号>`）
- `↑` / `↓` 切换运行，`←` / `→` 切换这次运行的步骤
- 每天随机抽几条「看起来成功」的记录标为「抽查」
- 筛选栏右边（刷新旁边）的垃圾桶「清空这一天」：点两下（第一下变成红色「确认清空」，4 秒内再点），这一天的记录和截图一起删，不弹对话框。不提供逐条删除：审计记录是事后查程序替你做了什么的依据，随手删单条就不可信了。旧记录按设置 › 录制与执行 › 「审计记录保留」自动清理（默认 30 天）
- 截图路径不在 `user_data` 里的记录（数据目录搬过家）只是不显示截图，不影响整个页面
